# Anvil — правила для сессий и агентов

Что это: командный центр программ на Rust (`crates/anvil`) и общий набор, из которого они собраны (`anvil-ui`,
`anvil-update`, `anvil-wallpaper`, `anvil-d3d`); с 29.10.2026 — ещё набор для Android-программ (`android/`). Где
остановились — [HANDOFF.md](HANDOFF.md); замысел и этапы — [SPEC.md](SPEC.md); работа идёт через OpenSpec
(`openspec/changes/<имя>`, правила владельца — в `openspec/config.yaml`, `context:`). Весь текст пользователю —
по-русски; интерфейс — RU/EN, светлая и тёмная тема.

## Публичный репозиторий

- Репозиторий открытый: закрытые проекты и репозитории владельца в новых текстах, коде, тестах и сообщениях
  коммитов не называть; данные в тестах и снимках — выдуманные.

## Диски и сборка

- Только **E:** — сборки, `target`, логи. JDK и SDK для Android только читаются с `D:\Android`
  (`JAVA_HOME='D:\Android\jdk-21'`, `ANDROID_HOME='D:\Android\Sdk'`); больше D: не трогать.
- Rust: по ходу — только затронутые крейты; при сдаче — полный прогон (скил `rust-verify`).
- Android (`android/`): `./gradlew … --max-workers=2`, после работы `./gradlew --stop`; Gradle и cargo одновременно не
  гонять, два Gradle одновременно — тоже.

## Работа агентов

- Исполнитель — свой worktree, коммиты по-английски в своей ветке, не пушит; называет ветку и хэш. Gradle и полный
  прогон cargo запускает оркестратор после слияния, если в задаче не сказано иное.
- Отчёт — до ~25 строк, подробности в `E:\dev_personal\Anvil-scratch\reports\<имя>.md`.
- Версии (набор `kit-v*`, приложение `v*`, Android-набор `android-kit-v*`) агент не меняет, если задача этого прямо не требует.

## Коммиты и выпуски

- Комментарии в коде — по-русски, всё, что печатается в консоль и журнал, — по-английски.
- Коммиты — по-английски. Пуш, теги и выпуски — по команде владельца.
