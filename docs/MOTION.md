# Движение в наборе `anvil-ui`

Единое место для всех анимаций семьи программ: шкала времени, кривые, «меньше движения» и готовые
эффекты. Код — `crates/anvil-ui/src/motion/`, живые примеры — вкладка «Движение» витрины. Этот файл
написан, чтобы другая сессия за пять минут нашла нужную анимацию, подключила её или поправила.

Появилось в 0.4.0 (29.09.2026): шкалу, кривые и флаг «Показывать анимацию» перенесли из Morok
(`crates/morok-desktop/src/motion.rs`, `sys/motion.rs`, решение 16 Morok) и добавили новые анимации.
Тег набора с этим — `kit-v0.4.0` (поставлен 29.09.2026 на коммит 9c6244f; программы остаются на прежних тегах, пока их не поднимут — по команде владельца).

## Быстрый старт (программа на egui)

```rust
// один раз при запуске — install уже зовёт motion::install и читает флаг Windows:
anvil_ui::install(&cc.egui_ctx, accent, theme);

// в начале каждого кадра (дёшево: флаг перечитывается по фокусу окна и раз в 3 с):
anvil_ui::motion::tick(ui.ctx());

// где угодно дальше:
use anvil_ui::motion::{self, Motion, effects, widgets as fx};
let motion = Motion::of(ui.ctx());
```

Ничего больше не нужно: крутилка, полоса хода, уведомления, ползунок сегментов и вкладок из набора уже
учитывают движение сами. Без `tick` всё работает, но смену системной настройки во время работы
программа не заметит — только при следующем запуске.

## Как найти нужное

| Хочу | Бери | Файл |
|---|---|---|
| Число длительности | константа шкалы (таблица ниже) | `motion/mod.rs` |
| Кривую | `ease_out`, `ease_in`, `ease_standard`, `ease_pop`, `linear`, `Curve` | `motion/curve.rs` |
| Плавно перейти к значению / цвету / состоянию | `Motion::toggle`, `value`, `color` | `motion/mod.rs` |
| Сыграть один раз / крутить по кругу | `Motion::once`, `Motion::cycle` | `motion/mod.rs` |
| Нарисовать дугу, кольца, галочку, точки, блик | `effects::*` (чистые функции поверх `Painter`) | `motion/effects.rs` |
| Готовый виджет | `widgets::*` (`fx::skeleton`, `fx::live_dot`, …) | `motion/widgets.rs` |
| Узнать, включено ли движение | `Motion::of(ctx).enabled` | `motion/mod.rs` |
| Выключить движение вручную | `motion::set_reduced(ctx, true)` | `motion/mod.rs` |

## Каталог анимаций

«Меньше» — что происходит при выключенном движении. Все примеры есть в витрине.

### Переходы (`Motion`, без рисования)

| Анимация | Вызов | Меньше |
|---|---|---|
| Приход/уход по кривой | `motion.toggle(ctx, id, value, motion::STATE)` → доля 0..1; уход всегда за `LEAVE` | сразу цель |
| Плавное число | `motion.value(ctx, id, value, motion::GRAPH)` | сразу цель |
| Плавный цвет | `motion.color(ctx, id, target, motion::STATE)` | сразу цель |
| Одноразовый ход | `motion.once(ctx, since, delay, secs)` → 0..1, просит кадры, пока идёт | 1 |
| Вечный цикл | `motion.cycle(ctx, period)` → фаза 0..1, кадры просит, пока спрашивают | 0 (стоит) |
| Встряска | `motion.shake(ctx, id, fire, amp)` → сдвиг по x | 0 |
| Вспышка изменившегося | `motion.flash(ctx, id, key)` → сила 1..0 | 0 |
| Появление строки | `motion.enter(ctx, id, index)` → (прозрачность, сдвиг y) | (1, 0) |
| Момент первого показа | `motion.first_seen(ctx, id)`; пропал на кадр — отсчёт заново | — |

### Эффекты (`effects`, рисуют по фазе)

| Эффект | Функция | Кто даёт фазу |
|---|---|---|
| Дуга ожидания (четверть окружности; `tail` — хвост) | `spin_arc(painter, c, r, w, color, phase, tail)` | `cycle(SPIN)` / `cycle(SPIN_SLOW)` |
| Кольца дымки стягиваются | `gather_rings(painter, c, &radii, color, cycle)` | `cycle(GATHER)` |
| «Подключено»: дымка → кольцо + волна | `settle(painter, c, &Settle{..}, t, w)` | `once(EMPHASIS)`, `once(WAVE_DELAY, WAVE)` |
| Мигание звена «идёт» | `blink(phase)` → прозрачность 1→0.35→1 | `cycle(BLINK)` |
| Галочка / крестик дорисовываются | `check_mark`, `cross_mark(painter, rect, t, stroke)` | `once(CHECK)` |
| Пинг живой точки | `ping(painter, c, from, to, color, phase)` | `cycle(PING)` |
| Три точки «печатает» | `typing_dots(painter, c, gap, r, color, phase)` | `cycle(DOTS)` |
| Скелетон: плашка + блик | `shimmer(painter, rect, corner, base, glow, Some(phase))` | `cycle(SHIMMER)`; `None` — без блика |
| Кольцо (в т.ч. пунктиром), дуга | `ring(..)`, `arc(..)` | — |

Чистая математика без рисования: `blink`, `shake_offset(t, amp)`, `flash(t)`, `enter(t)`, `stagger(index)`.

### Готовые виджеты (`widgets`, обычно берёшь их)

| Виджет | Вызов |
|---|---|
| Скелетон | `fx::skeleton(ui, size)` |
| Живая точка | `fx::live_dot(ui, Tone::Success)` |
| «Печатает…» | `fx::typing_dots(ui)` |
| Значок результата (круг + галочка/крестик) | `fx::result_mark(ui, key, ok, size)` — `key` меняют, чтобы сыграть заново |
| Встряска содержимого | `fx::shake(ui, key, fire, 6.0, \|ui\| …)` — `fire` истинно в кадре ошибки |
| Появление строки списка | `fx::enter(ui, key, index, \|ui\| …)` |
| Вспышка изменившегося | `fx::changed_highlight(ui, rect, key, value)` — до содержимого строки |
| Раскрытие по высоте | `fx::reveal(ui, key, open, \|ui\| …) -> Option<R>` |

### Что набор анимирует сам

`widgets::spinner`, `widgets::progress` (доля плавно за `GRAPH`; «неизвестно» — бегущий отрезок,
при выключенном движении — неподвижный посередине), `widgets::segmented` и `widgets::tabs` (ползунок
и полоска скользят за `LAYOUT`), `widgets::Toasts` (появление и затухание; выключено — просто есть),
переключатели и диалоги egui (через `style.animation_time`, его ставит `motion::install`).

Секунды. Значения в коде — `motion/mod.rs`; тест `scale_is_documented` следит, чтобы каждое имя здесь
было. Менял число — поправь и эту таблицу.

| Константа | мс | Кривая | Для чего |
|---|---|---|---|
| `PRESS` | 90 | out | нажатие: круг до 0.97 |
| `HOVER` | 120 | out | подсветка под курсором |
| `STATE` | 180 | out | смена состояния, появление диалога и меню |
| `LEAVE` | 120 | in | уход диалога, меню, всплывающего |
| `LAYOUT` | 200 | out | баннер, сворачивание круга, ползунок вкладок |
| `ENTER` | 240 | out | появление строки списка |
| `GRAPH` | 300 | out | новая точка графика, масштаб, доля полосы |
| `SHAKE` | 420 | linear | встряска при ошибке (затухающие три размаха) |
| `CHECK` | 380 | pop | галочка результата |
| `FLASH` | 900 | out | вспышка изменившегося гаснет |
| `EMPHASIS` | 520 | out | «Подключено»: дымка сгущается в кольцо |
| `WAVE` | 600 | out | волна после «Подключено» (`WAVE_DELAY` 420 — задержка) |
| `SPIN` | 1000 | linear | оборот дуги ожидания |
| `SPIN_SLOW` | 1600 | linear | оборот дуги переподключения |
| `GATHER` | 1600 | standard | кольца дымки стягиваются |
| `BLINK` | 1200 | standard | мигание звена «идёт» |
| `SHIMMER` | 1500 | linear | блик скелетона |
| `PING` | 1800 | out | кольцо живой точки (70 % цикла ход, потом пауза) |

## Кривые

`cubic-bezier(x1, y1, x2, y2)` как в CSS, `bezier(x1, y1, x2, y2, t)`.

| Функция | Кривая | Когда |
|---|---|---|
| `ease_out` | (0.16, 1, 0.3, 1) | приход: быстро и мягкое торможение — почти всё |
| `ease_in` | (0.7, 0, 0.84, 0) | уход: разгон и резкий конец |
| `ease_standard` | (0.4, 0, 0.2, 1) | туда-обратно внутри цикла: мигание, стягивание |
| `ease_pop` | (0.34, 1.56, 0.64, 1) | один акцент с лёгким перелётом (галочка); не для постоянных переходов |
| `linear` | — | вращение, бегущий блик |

## «Меньше движения»

Источники: флаг Windows «Показывать анимацию» (`SPI_GETCLIENTAREAANIMATION`) и ручное
`motion::set_reduced`. Что делает выключенное движение — колонка «Меньше» выше. Общие правила:

- переходы мгновенные, `style.animation_time = 0` (диалоги и переключатели egui тоже);
- ожидание — неподвижная дуга (`cycle` = 0), никакого перерисовывания;
- встряска, вспышка, появление, пинг и блик не играют, галочка сразу целиком;
- смысл не теряется: состояние всё равно видно цветом, значком и текстом.

`WM_SETTINGCHANGE` winit наружу не отдаёт, а подмена оконной процедуры ради одного флага хрупка —
поэтому флаг перечитывается при получении окном фокуса и не чаще раза в 3 с на кадрах, которые окно
и так рисует (`motion/pref.rs`). Вне Windows флаг пока не читается — всегда «включено».

## Правила

1. Короткие переходы 90–300 мс; один яркий момент на экран (сгущение «Подключено»).
2. Бесконечное движение — только пока идёт процесс. Кадры просит `cycle`/`once`, пока их спрашивают;
   ушёл процесс — перестал спрашивать — окно в покое, ничего не тратит. Никакого «дыхания» в покое.
3. Числа времени — только из шкалы, цвета — только из `Palette`. Своё число нужно — заведи константу,
   добавь строку в `SCALE`, в таблицу выше и в витрину.
4. Любая анимация обязана иметь «Меньше» и проходить тест «в покое кадров не просит».

## Как добавить или поправить

**Поменять длительность или кривую.** Правь константу в `motion/mod.rs` (и `Step` в `SCALE`, и таблицу
выше); всё, что на неё опирается, подхватит само. Проверь витрину обеих тем.

**Добавить эффект.** В `effects.rs` — функция `fn(.., phase: f32)`: без состояния, без времени, цвета
параметрами. Фазу даёт `Motion::once`/`cycle`. Нужна память между кадрами (что было раньше) — метод у
`Motion` по образцу `flash`/`shake` (состояние в `ctx.data` по `Id`, повтор через новый ключ).
Тест: «начинается и кончается на месте» и «в покое не просит кадров» (образцы — в конце файлов).

**Добавить виджет.** В `widgets.rs`: бери `Motion::of(ui.ctx())`, при `!enabled` рисуй статичный вид,
размер занимай одинаковый и при движении, и без. Дочерний `Ui` с движущимся содержимым делай через
`shifted` (тот же `id_salt` каждый кадр — идентификаторы внутри не прыгают).

**Всегда:** строка в витрине (`crates/anvil-ui/examples/gallery/motion_page.rs`), строка в каталоге
выше, запись в `HANDOFF.md` Anvil. Не забыть английский вариант подписи в витрине.

**Проверка:**

```bash
cargo test -p anvil-ui motion                # переходы, эффекты, «в покое», шкала описана здесь
cargo clippy -p anvil-ui --all-targets -- -D warnings
cargo run -p anvil-ui --example gallery -- --tab motion [--dark|--light] [--en|--ru] [--reduced]
```

Флаги витрины: `--size 1440x1000` (окно), `--scroll 700` (прокрутить вниз на первом кадре — для
снимков нижней половины), `--reduced` (сразу «меньше движения»). Снимок окна — `PrintWindow` по окну
процесса (см. HANDOFF, «Как здесь работать»); движение по снимку не видно — его проверяют глазами и
тестами.

## Подключить в программу

Программа берёт набор git-зависимостью по тегу: `anvil-ui = { git = "https://github.com/AgitAngst/Anvil", tag = "kit-v0.4.0" }`.
До тега — правка на живую: `[patch."https://github.com/AgitAngst/Anvil"]` на путь в `.cargo/config.toml`
программы (файл в `.gitignore`; перед коммитом убрать патч, иначе `Cargo.lock` запомнит путь).
Поднять тег набора — «Поднять до kit-…» в Anvil (Зависимости), только по команде владельца.

### Переезд Morok (сделан 30.09.2026: Morok 0.2.3, коммит `61ff1bf`)

Другая сессия перевела Morok на `kit-v0.4.0`: свои `motion.rs` и `sys/motion.rs` удалены, окно берёт
`anvil_ui::motion`. Шаги оставлены как образец для следующей программы со своей копией движения.
API перенесён под теми же именами, переезд механический:

1. `crates/morok-desktop/src/motion.rs` удалить; `use crate::motion::{self, Motion}` →
   `use anvil_ui::motion::{self, Motion}` (константы `PRESS`, `STATE`, …, методы `toggle`/`value`/`once`/`cycle`,
   кривые — те же). `motion.enabled` остался полем.
2. `sys/motion.rs` удалить; `MotionPref` заменить вызовом `anvil_ui::motion::tick(ctx)` в `logic` и
   `Motion::of(ctx)` вместо своего `Motion { enabled }` в `App`; блок «Меньше движения» в `app.rs`
   (`desk.motion.enabled(ctx)` … `all_styles_mut`) уходит целиком.
3. В `ui/orb.rs` рисование — `effects::gather_rings`, `effects::settle`, `effects::spin_arc`, `effects::ring`;
   в `ui/chain.rs` — `effects::blink`. Числа те же, картинка не должна измениться (сверить снимками
   `--screenshot`).
4. Тесты «анимация выключена — всё мгновенно» и «в покое переходов нет» переехали сюда
   (`motion::tests`) — у Morok остаются только сценарные.

## Анимированные значки программ

Значок программы (окно, панель задач, трей, «О программе») — картинка, а не фигуры egui, поэтому его кадр считает
свой растеризатор, а ход берёт чистая машина состояний. Способ один у трёх описаний (30.09.2026, интеграцию делают
другие сессии):

| Программа | Изменение OpenSpec | Что анимируется |
|---|---|---|
| Morok | `openspec/changes/morok-mark-motion` | маршрут M: искра по звеньям цепочки, красная ошибка, «загорается», трей, «О программе» |
| Amber (клиент) | `openspec/changes/amber-mark-motion` | «Набирает»: три точки в реплике → пузырьки воздуха; события трея (сообщение, звонок, непрочитанное) |
| Amber Admin | `openspec/changes/admin-mark-motion` | «Полоска хода» на сервере: ход задач, готово, красная ошибка |

Общий порядок, который сработал: выбрать вариант из показа → описание как изменение OpenSpec (`proposal`, `design`,
`tasks`, `spec`) → **эталон `reference/mark-motion.html`** с теми же числами, что пойдут в Rust (параметры
`?scenario=…&at=…&still=1&px=1` для снимков headless-Edge) → сцена значка на общей машине состояний (`motion::machine`,
раздел ниже) с тестами → растеризатор кадра
в RGBA → подключение. Правила те же, что выше: кадров в покое нет, «меньше движения» уважается, красное — ошибка и
движение стоит, пока её не исправят.

## Машина состояний значка (`motion::machine`)

С 0.6.0 (01.10.2026, по просьбе владельца: «машину состояний сделай универсальной для разных типов анимаций, и пусть
она лежит в Anvil»). Ход значка — общий, программе остаются своё состояние, свои числа и свой растеризатор. Код
чистый, без egui; время — секунды `f64` от часов программы (`Instant` при запуске).

| Кирпичик | Что это | У кого |
|---|---|---|
| `Phase<S>` | состояние с переходами: `set`, `state`, `prev`, `age`, `is(from, to)` | связь Amber, режим центра, маршрут Morok |
| `Pulse` | одноразовое событие: `fire`, `playing(now, secs)`, `window(now, delay, secs)`; подряд — заново | сообщение |
| `Hold` | пока включено — цикл: `set(on, now)`, `cycle(now, period)` | звонок |
| `Badge` | счётчик: 0 → n — всплеск (`pop()`), n → m — без повтора, → 0 — сразу гаснет | непрочитанное |
| `Follow` | число догоняет цель (`tau`), `reset` — встать сразу, `still` — сразу к цели | доля хода центра |
| `Script<S>` | состояния по очереди с длительностями; `drive(&mut phase, now)` ставит смены в их моменты | «О программе» |
| `window(t, delay, secs)` | доля 0..1 внутри отрезка эпизода | блик, кольцо |
| `Scene` | значок программы: `frame`, `wants_frames`, `at_rest`, `key` | у каждой программы своя |
| `Presenter<K>` | показ: `step` → `Show::{Keep, File, Frame}`, `next_in` — когда просить кадр, `invalidate` | окно, трей |

Как подключить значок:

```rust
use anvil_ui::motion::machine::{Phase, Pulse, Presenter, Scene, Show};

struct MyMark { link: Phase<Link>, message: Pulse }          // свои кирпичики
impl Scene for MyMark { /* frame: числа для своего растеризатора; at_rest: выглядит как файл */ }

// в logic (идёт и при спрятанном окне), часы — секунды от запуска:
match window_show.step(&mark, now, !Motion::of(ctx).enabled) {
    Show::Frame(f) => ctx.send_viewport_cmd(ViewportCommand::Icon(Some(Arc::new(render(&f, 64))))),
    Show::File => ctx.send_viewport_cmd(ViewportCommand::Icon(Some(Arc::new(window_icon())))),
    Show::Keep => {}
}
if let Some(secs) = window_show.next_in(&mark, now, still) { ctx.request_repaint_after(Duration::from_secs_f64(secs)) }
```

Правила `Presenter`: в покое (`at_rest`) — файл программы и **ни одного кадра**; пока движется (`wants_frames`) — кадры
не чаще потолка (значок окна и трея — 10 в секунду); неподвижный не-покой (остывший значок, ошибка, «меньше движения»)
— один кадр на каждую смену `key`. Растеризатор у каждой программы свой (формы знака разные). Первая программа на
машине — Amber (`amber-desktop/src/mark_motion.rs`), за ней — центр и Morok по своим изменениям OpenSpec.

## Чего ещё нет (идеи, по желанию владельца)
