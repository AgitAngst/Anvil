# Узоры обоев в наборе

Фон бесед с неброским узором — как обои у Telegram, только свои. Один набор узоров на все программы и
клиенты: плитку рисует крейт `anvil-wallpaper` (без зависимостей), egui-программы берут готовую текстуру из
`anvil_ui::wallpaper`, клиенты не на Rust — PNG-плитки. Этот файл написан, чтобы другая сессия за пять минут
взяла узор в свой клиент или добавила новый.

Появилось в 0.5.0 (30.09.2026) по просьбе владельца: «Добавь новых паттернов обоев в анвил, чтобы можно было
забрать в любой другой клиент». Первые пять узоров перенесены из `amber_core::wallpaper` (Amber, 26.09) бит в
бит; шесть — новые. Тег набора с этим ещё не поставлен — только по команде владельца.

## Узоры

| Код | Русский | English | Что на плитке |
|---|---|---|---|
| `amber` | Янтарь | Amber | колечки, точки, искорки, сердечки — узор Amber с первого дня |
| `stars` | Звёзды | Stars | звёзды, месяцы, искорки |
| `geometry` | Геометрия | Geometry | треугольники, ромбы, крестики, кольца (контуром) |
| `garden` | Сад | Garden | листья с прожилкой и цветы |
| `waves` | Волны | Waves | отрезки волн и пузырьки |
| `honeycomb` | Соты | Honeycomb | шестиугольники контуром и залитые — к значку Anvil |
| `snow` | Снег | Snow | снежинки «ёлочкой», крупа, искорки |
| `space` | Космос | Space | планеты с кольцом, звёзды, искорки |
| `paws` | Лапки | Paws | кошачьи лапки и сердечки |
| `confetti` | Конфетти | Confetti | полоски, квадратики, завитки, кружки |
| `dots` | В точку | Dotted | ровная сетка точек 12×12, как бумага в точку |
| `plain` | Без узора | Plain | только фон |

Порядок — `Pattern::ALL`, так их и показывают в выборе; «Без узора» всегда последним. Код хранится в настройках
(`Pattern::code`, `Pattern::from_code`); незнакомый код — «Янтарь», чтобы настройки из более новой версии не
ломали фон. Названия — `title_ru()`/`title_en()` (или `anvil_ui::wallpaper::title(pattern, lang)`); у Amber свои
строки через `t!`/`tr` — там названия переводит словарь программы.

## Правила

- **Плитка 192 точки (`TILE`), без швов:** фигуры считаются через расстояние до края и заворачиваются через край
  плитки (тор). Повторять плитку можно сколько угодно.
- **Неброско:** узор проступает сквозь фон не сильнее `STRENGTH` = 0.13 и закрывает 1–15 % плитки (тест
  `every_pattern_is_sparse…`). Узор — фон, а не картинка: переписка читается поверх.
- **Цвета — от темы клиента.** `tile(pattern, scale, bg, ink)`: `bg` — фон бесед темы, `ink` — цвет узора. Смешение —
  в гамме, как `Color32::lerp_to_gamma` у egui. У Amber: светлая — фон `#EEE5D3`, узор `#6E5A3A`; тёмная — `#12100E` и
  `#CDBFA8`. Сменили тему — перерисовать плитку новыми цветами (кэш `Tiles` делает это сам по ключу цвета).
- **Непрозрачная плитка:** фон запечён в неё. Полупрозрачную egui смешивал по-своему, и узор пропадал.
- **Резкость:** `scale` — пикселей на точку (плотность экрана у телефона, `pixels_per_point` у egui); на 150 %
  плитка 288×288, на 3× — 576×576.
- **Одинаково всегда:** фигуры расставлены не случайно, а по счётчику с зерном узора — узор не «прыгает» между
  запусками и машинами. Первые пять узоров сверяются с Amber по хэшам (тест под Windows: `sin` и корень у разных
  libm расходятся в последнем бите).

## Как взять в свой клиент

**Программа на egui** (как десктоп Amber):

```rust
use anvil_ui::wallpaper::{self, Pattern, Tiles};

// в состоянии окна:
tiles: Tiles,

// где рисуется лента:
if let Some(texture) = self.tiles.get(ctx, pattern, palette.chat_bg, palette.pattern) {
    wallpaper::paint(ui.painter(), feed_rect, &texture);
}
// образец в выборе узора — вдвое мельче: egui::Image::new((texture.id(), size)).uv(wallpaper::uv(size * 2.0))
```

**Ядро без окон** (телефон через UniFFI, бот, сервер страниц): зависимость на `anvil-wallpaper`, дальше
`anvil_wallpaper::tile(pattern, scale, bg, ink)` → `(side, rgba)`, RGBA построчно, непрозрачная. Телефон Amber так и
делает: фасад отдаёт `wallpaper_patterns()` и `wallpaper_tile(code, scale, bg, ink)`, Kotlin делает из плитки
`ImageBitmap` с повтором.

**Клиент не на Rust, макет, страница:** PNG-плитки.

```text
cargo run -p anvil-wallpaper --example export --release -- [ПАПКА] [--scale 2] [--bg EEE5D3 --ink 6E5A3A]
```

Без `--bg`/`--ink` — по две плитки на узор цветами Amber (`<код>-light@2x.png`, `<код>-dark@2x.png`), с ними — одна
(`<код>@2x.png`). PNG собирается без зависимостей и сжат просто (фильтр Sub и повторы) — 10–30 КБ на плитку.
В CSS: `background: #EEE5D3 url(stars-light@2x.png) 0 0 / 192px 192px repeat;`.

## Как добавить узор

1. `Pattern`: новый вариант **перед** `Plain`, в `ALL`, `code`, `title_ru`, `title_en`.
2. `layout`: своё зерно (`seed`) и фигуры по `k` в решётке 4×4 (или своя раскладка, как `dotted`).
   **Первые пять не трогать:** их фигуры, порядок вызовов счётчика и повороты сверяются с Amber по хэшам.
   Повороты нового узора — своими ветками **выше** общих (`(_, Shape::Leaf …)`), иначе у старых сдвинется счётчик.
3. Новая фигура — вариант `Shape` и расстояние до края в `coverage` (отрицательное внутри). Формулы — у Иниго
   Килеса (sdHexagon, sdStar5, sdHeart…). Старую фигуру не менять: на ней держатся прежние узоры — для нового
   вида заводится новая (как `HeartExact` рядом с `Heart`).
4. Тесты: `every_pattern_is_sparse…` проверит плотность, `a_shape_is_solid_inside…` — добавить фигуру туда же.
5. Посмотреть глазами: `--example export` и открыть PNG (узор бледный — для проверки удобно поднять яркость).
6. Программы получат узор, когда их поднимут на новый тег набора; Amber ещё и переводит название (`t!`/`tr`).

## Что где

- `crates/anvil-wallpaper/src/lib.rs` — узоры, фигуры, плитка, тесты.
- `crates/anvil-wallpaper/examples/export.rs` — PNG-плитки.
- `crates/anvil-ui/src/wallpaper.rs` — текстура egui (`image`, `Tiles`, `paint`, `uv`, `title`).
