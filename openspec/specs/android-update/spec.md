# android-update Specification

## Purpose
Обновление Android-программы семьи изнутри: найти на GitHub выпуск новее, предложить его без навязчивости, скачать
APK, проверить контрольную сумму и отдать установщику системы — как `anvil-update` на ПК.

## Requirements

### Requirement: Check for a newer release
Программа SHALL проверять выпуски репозитория при каждом запуске (раз за процесс), если в настройках включено
«Проверять обновления» (по умолчанию включено), и по кнопке — всегда. Ошибки авто-проверки не показываются. Выбирается самый новый выпуск новее текущей
версии; черновики не в счёт; пред-выпуски — только при включённом «Предлагать пред-выпуски». Выпуск, который человек
пропустил, при автоматической проверке MUST NOT предлагаться снова.

#### Scenario: Newer stable release
- **WHEN** текущая версия 0.3.0, а в репозитории есть v0.3.1 и v0.4.0-beta.1, пред-выпуски выключены
- **THEN** предлагается v0.3.1

#### Scenario: Skipped version
- **WHEN** человек нажал «Пропустить эту версию» у v0.3.1 и программа снова проверяет сама
- **THEN** баннер не показывается, а проверка по кнопке v0.3.1 показывает

### Requirement: Rate limit fallback
Когда API GitHub отвечает 403 или 429, программа SHALL узнать последний обычный выпуск по переадресации
`<сайт>/<репозиторий>/releases/latest` и взять файлы по адресам из соглашения. Не вышло и это — ошибка с числом
минут до сброса лимита, понятным текстом на языке программы.

#### Scenario: Limit with the fallback working
- **WHEN** API отвечает 403 с исчерпанным лимитом, а `releases/latest` переадресует на тег v0.3.1
- **THEN** предлагается v0.3.1 без заметок к выпуску

### Requirement: Verified install
Программа SHALL скачивать APK `<app>-X.Y.Z-android.apk` и устанавливать его только при совпадении SHA-256 со строкой
в `SHA256SUMS`. Без `SHA256SUMS`, без строки для файла или при несовпадении суммы установка MUST NOT начинаться.
Установку подтверждает человек в окне системы; без разрешения «Установка неизвестных приложений» программа SHALL
объяснить, зачем оно, и открыть его настройку.

#### Scenario: Checksum mismatch
- **WHEN** сумма скачанного APK не совпадает со строкой в `SHA256SUMS`
- **THEN** файл удаляется, показывается ошибка «Контрольная сумма не совпала», установка не начинается

#### Scenario: Install permission missing
- **WHEN** APK проверен, а разрешения на установку у программы нет
- **THEN** показывается строка, зачем оно, и кнопка, открывающая его настройку

### Requirement: Unobtrusive UI
Найденное обновление SHALL показываться баннером над содержимым (без окон при запуске) с действиями «Обновить»,
«Что нового», «Позже», «Пропустить эту версию»; скачивание — с ходом и «Отменой»; в «О программе» — состояние и одна
кнопка по нему. Все тексты — на русском и английском.

#### Scenario: Later
- **WHEN** человек нажал «Позже»
- **THEN** баннер исчезает до следующего запуска программы
