## Why

Владелец (28.10.2026, план эволюции Anvil, этап 5): минуты GitHub Actions считаны, место на диске E: конечно, а `target` растёт.
Решение по дискам: «просто SMART», без порогов.

## What Changes

- Вид «Ресурсы и бюджет» (значок монитора над списком проектов, палитра `Ctrl+K`): диски C:, D:, E: и диски сборок — свободно из всего;
  SMART физических дисков (исправность, износ, температура, часы, ошибки чтения — что отдаёт Windows, без порогов); размер `target`
  каждого проекта с кнопкой «Очистить» (то же подтверждение `cargo clean`); минуты Actions закрытых репозиториев за месяц.
- Минуты — оценка по длительности завершённых прогонов (`/actions/runs`, округление вверх до минуты, Windows за одну); лимит в месяц
  (по умолчанию 2000) правится в виде и хранится в `anvil.toml` (`actions_quota`).
- Версия приложения 0.8.0; набор не меняется.

## Non-goals

Пороги и предупреждения по SMART; точный учёт биллинга (нужны права на биллинг); удаление чего-либо без подтверждения.

## Impact

`crates/anvil`: `resources.rs`, `ui/resources.rs`, `github.rs` (`Cmd::Minutes`, `Usage`, `month_start`), `config.rs`, `app.rs`,
`ui/sidebar.rs`, `ui/palette.rs`, `Cargo.toml` (`Win32_Storage_FileSystem`), `lang/en.tsv`.
