## Why

Владелец (28.10.2026): «Каталог программ» — не магазин. Нужен вид, где видны программы всех репозиториев аккаунта, а не только склонированных
проектов, и где их ставят прямо из выпусков, без клонирования. Макет согласован в чате; решения владельца: магазин заменяет каталог,
показываются репозитории с выпуском и архивом под Windows (остальные — под «Показать без выпусков»), инструменты видны с пометкой.

## What Changes

- Вид «Магазин программ» вместо «Каталога программ» (меню «Другие виды», палитра): репозитории аккаунта (без форков и архивных) и
  подключённые проекты; выпуски читаются по API (`Cmd::StoreScan`), программы берутся из архивов выпуска по соглашению
  `<программа>-X.Y.Z-windows-x64.zip` + `SHA256SUMS`.
- Карточка программы: название, описание репозитория, бейдж состояния («Установлена X», «X → Y», версия выпуска, «Ставлю…», «!»),
  действие («Запустить», «Обновить», «Установить», «Повторить»). Сведения по щелчку: версия, последний выпуск, размер, «Заметки выпуска»,
  «Страница на GitHub», «Удалить».
- Фильтры «Все / Установленные / Обновления», поиск, «Обновить все · N»; «Показать без выпусков» раскрывает репозитории без программ.
- Установка идёт задачей скачивания (SHA-256 сверяется), без клонирования; ход — в карточке.
- Убирается «перенос списком» каталога (скопировать и вставить): на новом ПК магазин сам показывает все репозитории аккаунта.
- Версия приложения 1.1.0; набор не меняется.

## Non-goals

Значки программ из репозиториев; скриншоты; отзывы и рейтинги; чужие аккаунты и организации вне доступа токена; установка без выпусков.

## Impact

`crates/anvil`: `store.rs`, `ui/store.rs`, `github.rs` (`Cmd::StoreScan`), `app.rs`, `sources.rs` (очередь клонирования убрана), `ui/sidebar.rs`,
`ui/palette.rs`, `ui/mod.rs`, `lang/en.tsv`; удаляются `catalog.rs`, `ui/catalog.rs`.
