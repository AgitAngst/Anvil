## REMOVED Requirements

### Requirement: Program catalog
**Reason**: Replaced by the program store, which covers repositories that are not connected as projects.
**Migration**: Use the "Program store" view.

### Requirement: Moving to another PC
**Reason**: The store lists all repositories of the account on a new PC, so copying a repository list is no longer needed.
**Migration**: Sign in to GitHub on the new PC and install from the "Program store" view.
