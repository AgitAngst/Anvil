# Proposal

## Why

Android-программы семьи раздаются APK из GitHub Releases (решение владельца 29.10.2026, Ampulse — первая). Без
обновления изнутри человек остаётся на старой версии навсегда. На ПК это делает `anvil-update`; шаг 3 плана
Android — то же для телефона в наборе Anvil, чтобы каждая программа не писала своё.

## What Changes

- Новый модуль `android/anvil-update` (библиотека, группа `io.github.agitangst.anvil`): проверка выпусков GitHub,
  выбор новее текущей версии (пред-выпуски — по флажку), обход лимита запросов через `releases/latest`, скачивание
  APK, сверка SHA-256 по `SHA256SUMS`, установка установщиком системы, понятные ошибки на языке программы.
- Готовые части на Compose: баннер «Вышла vX · Обновить · Что нового · Позже · Пропустить эту версию», ход
  скачивания, «Что нового», раздел настроек «Обновления» (проверять, предлагать пред-выпуски, пояснение про сеть),
  состояние и кнопка для «О программе».
- Модуль объявляет `INTERNET` и `REQUEST_INSTALL_PACKAGES`: программа подключает его только в сборке `github`.
- Пример-приложение `sample` показывает баннер, «Обновления» и «О программе» с проверкой.
- Версия Android-набора 0.1.0 → 0.2.0 (этап).

## Capabilities

### New Capabilities
- `android-update`: обновление Android-программы из GitHub Releases изнутри (сборка `github`).

### Modified Capabilities

## Impact

- Новые файлы: `android/anvil-update/`, строка в `android/settings.gradle.kts`; правки `sample`.
- Новых библиотек нет: сеть — `HttpURLConnection`, JSON — свой небольшой разбор, установка — `PackageInstaller`.
- Документы: `docs/ANDROID.md` (§6, §13), `docs/RELEASES.md` («Как устроено обновление»), `SPEC.md`, `HANDOFF.md`.
- Rust-часть и `anvil-update` для ПК не меняются.
