## Why

Владелец (29.10.2026): из Anvil нужно уметь ставить серверы своих программ на Linux-машины и управлять ими, причём так, чтобы
новые серверы добавлялись без переписывания центра, а часть серверов была скрыта. «Парк серверов» (0.9.0) только проверяет
порт и запускает команды владельца; по SSH он не ходит и ничего не ставит.

## What Changes

- Вид «Серверы» (меню «Другие виды», палитра `Ctrl+K`): слева машины, справа открытая машина и установленные на ней модули.
  «Парк серверов» остаётся для записей «только проверка».
- Новый крейт `anvil-servers` (в наборе Anvil, без графики): SSH с запоминанием ключа машины, секреты в хранилище учётных
  данных, скачивание выпусков с проверкой `SHA256SUMS`, задачи с ходом работы и скрытием токенов, разбор манифеста модуля.
- **Модуль** — манифест TOML (`id`, имя, значок, `hidden`, источник файла по архитектурам, службы, порты, команды
  `install | status | backup | uninstall | update`, действия, форма настроек, признак «несколько экземпляров»). Для нетиповых
  страниц позже — код на Rust; в этом изменении только манифест.
- Реестр: встроенные модули и `modules/*.toml` в папке настроек. Скрытые модули видны только при включённом переключателе
  «Скрытые модули» в настройках.
- Установка модуля на машину: выбор модуля → форма → ход работы → итог. Общие вкладки машины: «Обзор», «Обслуживание»,
  «Журнал», «Консоль».
- Контракт сервера: `<бинарник> install | status --json | backup | uninstall`. Первый встроенный модуль — сервер-ретранслятор
  Ampulse (изменение `ampulse-relay` в его репозитории).
- Версия приложения 1.2.0; набор получает новый крейт — версия набора растёт только при теге `kit-v*` по слову владельца.

## Non-goals

- Перенос экранов существующих закрытых админок в Anvil; их модули подключаются только манифестом-адаптером «открыть программу и
  прочитать сводку».
- Серверы не на Linux или без systemd; Docker; автообновление по расписанию; управление ботами.
- Названия закрытых проектов в коде, документах и тестах репозитория.

## Impact
